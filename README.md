# P+L 4 — Unidentified Specimens

Interactive 3D viewer for the unidentified hominin crania and mandibles used in
Practice + Learn 4 (ANTH 5A, Brandeis University).

Each specimen is shown unlabeled, identified only by its worksheet code (S1–S9, M1/M3/M4)
and, for the skulls, its cranial capacity. The Sketchfab model titles are hidden so that
students work from the morphology rather than from a filename.

**Live page:** https://nsusmann.github.io/anth5a-pl4-specimens/
